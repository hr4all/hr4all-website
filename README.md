# HR4All Landing Page

Professional landing page for HR4All, a Spanish HR consulting firm for SMEs in Argentina.

## Tech Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Lucide React icons

## Run Locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.
